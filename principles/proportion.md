# 分寸 (`proportion`)

## 定义

分寸问的是：声称强度与证据强度是否匹配。试点、demo、个例、未验证推断，不能写成已验证结论或普遍规律。过度周全、两面讨好、永不下判断，同样是分寸失调——用「平衡」逃避与证据相称的立场。

## 评审问句

- 声称强度与证据强度是否匹配？
- 是否把 demo / 试点 / 个例说成结论或规律？
- 是否为了「显得客观」而过度周全，结果没有与证据相称的立场？

## AI 初稿典型病征

- demo 说成结论：「演示通过」写成「已验证可推广 / 生产就绪」。
- 个例说成规律：一次客户反馈写成「用户普遍认为」。
- 未验证说成已验证：「计划中」「假设」被滑成「事实证明」。
- 过度周全无立场：利弊各写一段对称套话，最后「需结合实际情况」，等于没写。
- 模态词错位：证据弱却用「必须」「显然」；证据强却只敢「或许」「某种程度上」。

## 改法

- 为关键声称标定证据等级：逸事 / 单次试点 / 对照结果 / 多方复核——用词与之对齐。
- 显式写出适用范围与反例条件；推广结论必须另有证据，不能靠语气升级。
- 允许清晰的有限结论：「在本次试点样本内成立；外推未验证。」
- 该站队时站队：在证据支持的范围内给推荐；范围外明确「不知道 / 未测」。

## 中文出处

「过犹不及。」声称与证据失配，或过（夸大），或不及（假平衡）。中文修辞传统重「得体」「适度」；本维在考据层落实为强度匹配，与辞章层「得体」互补而不混淆。

## 英文出处

科学与工程沟通的基本纪律：do not overclaim。Orwell 批评的「伪精密」与空洞强调，常与分寸失控伴生；另可对照任何实验报告规范：limitations 与 claims 同级呈现。见 `traditions/orwell-politics-and-english.md`（待建）中对夸张与含混的映射。
