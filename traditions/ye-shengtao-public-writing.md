# 叶圣陶：先对读者负责，再谈文字

## 出处

叶圣陶《文风的问题在哪儿》（1958-03-18）与《怎样改进文风》（1958-03-20）。可从 [民进网转载页](http://www.gdmj.org.cn/jqgz/xxyd/content/post_1141313.html) 查阅；纸本收录与初刊版本请另行核对。

## 可转化的两条原则

### 1. 面向公众的文字，要给读者一个理由

写之前先问：这段文字让读者获得什么？它可以帮助读者理解一个事实、判断一个问题，或完成一项行动。若只是把作者尚未想明白的内容排成段落，语言越工整，空处越显眼。

这对应本仓库的 `intent`、`logic` 与 `selection`：文章要有值得写下来的判断，材料要支持判断，篇幅要留给真正必要的内容。

### 2. 修改先查病因，再改句子

词句不当，有时只是表面。真正的问题可能在事实不准、理解含混、主张过强、结构失序，或不愿删去可有可无的话。修改应先找到问题所在，再决定是否动词、换句或重排段落。

这对应 `sources`、`proportion`、`stale-words` 与 `qi`。事实核验独立成门；语言检查不能拿来证明内容已经可靠。

## 可执行检查

1. 每一段能否回答“它为读者补上了什么”？
2. 删除一句后，事实、判断、关系或行动有没有损失？没有就删。
3. 若句子读不懂，先回到它要表达的事实或判断，再改语序和用词。
4. 改完后重看范围、条件、否定和责任主体，确认没有把原意改强或改弱。

## 边界

- “简洁”不等于压缩篇幅；复杂问题需要完整解释时，长文可以保留。
- “自然”不等于口语化；正式文体可以使用必要术语和完整句法。
- 这两篇文章提供的是公共写作的判断问题，不替代领域审查、版权审查或事实核验。
