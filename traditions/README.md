# 写作材料与参照

本目录按语言和材料性质组织。先选语言，再选材料类型；同一篇材料只归入一个类别。索引页只负责导航，不与材料并列。

## 分类规则

| 第一级 | 第二级 | 归类依据 |
|---|---|---|
| 中文材料 | 原典与古典文论 | 以古代文本或传统文论为直接对象 |
| 中文材料 | 现代作者写作论述 | 以近现代作者的写作理论或文章为直接对象 |
| 中文材料 | 当代署名文章 | 有明确作者、刊载载体和发表信息的当代文章 |
| 中文材料 | 官方规范 | 由机构公开发布、适用范围明确的规范 |
| 英文材料 | 英文写作指南 | 面向一般或专业写作的著作与文章 |
| 英文材料 | 学术写作研究 | 描述或教授特定学术体裁的研究与模型 |

“可访问转载”“电子整理版本”是访问方式，不是材料类别；它只说明读者如何核对，不能替代初刊、原书或正式版本。

## 使用原则

1. 先确认材料是否适合当前文体、读者和问题。
2. 将原文短摘、仓库转述和仓库规则分开。
3. 需要准确引用时，回到原书、原刊或正式版本核对。
4. 一条规则进入默认标准前，还须满足 [维护说明](../MAINTENANCE.md) 的准入条件。
