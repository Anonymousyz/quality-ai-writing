## 来源标签

- **原典 / 经典著作：** 用于理解概念与传统。准确引文必须核对作者、篇目、版本与上下文。
- **作者原文 / 署名文章：** 用于讨论明确的写作问题。转述须保留原文的范围和语气。
- **官方规范：** 适用于其定义的产品或界面场景；不应外推到所有文体。
- **可访问转载或电子整理版本：** 便于阅读和核对，不等同于初刊或唯一版本。

## 使用原则

1. 先问材料是否适合当前文体、读者和问题。
2. 将原文短摘、仓库转述和仓库规则分开。
3. 需要准确引用时，回到原书、原刊或正式版本核对。
4. 一条规则进入默认标准前，还须满足 [维护说明](../MAINTENANCE.md) 的准入条件。
