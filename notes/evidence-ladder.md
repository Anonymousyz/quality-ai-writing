# 证据阶梯（声称强度对齐）

分寸维要求：声称强度与证据强度匹配。本注给一个**可公开的启发式阶梯**，不是实验室计量。

## 阶梯（弱 → 强）

| 等级 | 证据形态（例） | 可支撑的声称语气 |
|---|---|---|
| E0 传闻 | 「听说」「好像」「模型记得」 | 不写进关键论断；最多标为未核 |
| E1 逸事 | 单人口头、一次演示观感 | 「有人反馈……」「演示时看起来……」 |
| E2 单次试点 | 小样本、无对照、自报指标 | 「在本次样本内……；外推未验证」 |
| E3 可复核测量 | 有基线/日志/可重复步骤 | 「在测量条件下……；误差/范围如下」 |
| E4 多方复核 | 独立来源或对照一致 | 「多项来源一致显示……；仍受限于……」 |

## 禁止的跳级

- E1/E2 →「已充分验证 / 可全面推广 / 事实证明」  
- E0 → 任何关键百分比或「业界共识」  
- 把 E2 的自报「约 40%」写成 E3/E4 语气

## 改法三步

1. 给关键声称标等级（可写在草稿旁注，公开稿可改成限定语）。  
2. 语气降到该级或以下；升声称必须先升证据。  
3. 写清适用范围与反例条件——「不知道」比假精密干净。
