# 一票否决快扫

署名前先扫否决带。触发任一条 → **本稿不合格**，不必先做八维细评。完整条文见 `STANDARD.md`。

## 五条（按检查动作）

| # | 否决 | 30 秒问法 |
|---|---|---|
| 1 | 关键事实错误或编造 | 关键数字/引文/专名能否指出出处？不确定是否已写成事实？ |
| 2 | 关键论断来源不可溯 | 「研究表明 / 内部数据 / 业界共识」旁有无可核对象？ |
| 3 | 过度声称 | demo/个例/未验证是否被写成已验证或普遍规律？ |
| 4 | 场合违规 | 是否含未授权、敏感、可识别内部材料？ |
| 5 | 通篇无人的判断 | 读者能否用一两句复述**主张**（不是话题）？ |

## 用法

1. 打开文稿，只做上表，不做润色。  
2. 触发 → 先改事实/来源/分寸/立意，再谈辞章。  
3. 未触发 → 再按风险选 `ai-prose-detect` / `mock-reader` / 八维全检（见技能 `pre-sign-review`）。

## 边界

- 否决快扫**不是**打分。  
- 「看起来像 AI」本身不是否决；空判断与编造才是。  
- 脱敏入库另见 `MAINTENANCE.md`，与否决第 4 条相关但目的不同。
