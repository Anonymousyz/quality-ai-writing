# 场景化选择：几组常见张力

下列张力不是对错题，而是**场景选择题**。选错场景，再顺的句子也不得体。

## 1. 结论先行 vs 铺垫后出结论

| 更宜结论先行 | 更宜铺垫后出结论 |
|---|---|
| 读者要快速决策；时间紧 | 结论可能不被接受，需先建立理解 |
| 结论已有接受基础 | 议题有争议，需带着读者走推理 |
| 执行摘要、决策备忘、例行汇报 | 研究说明、需说服的论证 |

元规则：知识工作默认**能结论先行就结论先行**；只有「先给结论会阻断阅读」时才铺垫。

## 2. 说清楚 vs 留余味

- **说清楚是底线**：行动、边界、责任不能靠读者猜。  
- **留余味是进阶**：核心论点清晰之后，论证过程可以给高阶读者留推导空间。  
- 禁止用「留白」「余味」掩饰没想清楚或没写清楚。

## 3. 情感克制 vs 情感力量

- 面向分析型读者、以数据为主的评审：克制宣告式情感（「高度重视」）。  
- 需要共鸣的开篇：情感应**经具体事实与案例传递**，而不是形容词加码。  
- 禁止空喊；不禁止内容本身的重量感。

## 4. 规范合式 vs 真实判断

- **底线**：该文体的基本规范要遵守（得体、可提交）。  
- **追求**：规范之内，核心论点必须是自己的真实判断，不是人云亦云。  
- 「合式」不是「合模版空话」。
