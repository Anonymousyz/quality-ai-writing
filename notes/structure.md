# 结构服务于推理与使用

结构不是固定模板，而是帮助读者完成任务的顺序。同一材料，给决策者、同行或公众，段落顺序可以不同。

## 常见安排（可选，非定律）

| 文本类型 | 通常优先呈现 |
|---|---|
| 决策文本 | 结论 → 理由 → 边界 → 行动 |
| 研究/分析 | 问题 → 已有认识 → 依据 → 发现 → 局限 |
| 探索笔记 | 问题与假说 → 竞争性解释 → 未决处 |
| 公开说明 | 尽早建立「问题—读者」关系，再给证据 |

金字塔、SCR、起承转合、图尔敏、MECE 等都是**可选工具**：有助于拆解时再用，不要当成每篇必须跑完的流程。  
需要检查「凭什么从证据跳到结论」时用 [toulmin-warrant.md](toulmin-warrant.md)；需要整理并列分类时用 [mece.md](mece.md)。

## AI 初稿常见结构病

- 先铺背景三页，结论藏在最后（决策读者用不上）
- 面面俱到的并列大纲，没有「因此」真正成立的一步
- 把探索笔记的未决语气，写成结论驱动的肯定句

## 与八维的关系

结构问题先在 `logic` / `selection` 上暴露，再落到段落衔接的 `qi`。改结构优先于改词语（见 [revision-order.md](revision-order.md)）。
