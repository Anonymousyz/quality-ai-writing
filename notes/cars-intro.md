# 研究开篇的 CARS 参照

CARS 描述研究论文引言常见的写作动作。本页只说明可迁移的部分：研究或较长论证开头，怎样让读者看到问题、缺口和本文的位置。

## 三步

| 动作 | 写作者在做什么 | 常见问题 |
|---|---|---|
| 建立领域 | 说明问题为何值得讨论 | 背景铺得太长，读者看不出“为什么是现在” |
| 指出缺口 | 写清疑问、争议或尚未解决的事 | 用“日益重要”代替具体缺口 |
| 说明位置 | 交代本文主张、目的、贡献或边界 | 只写“本文将探讨”，没有说清本文做什么 |

## 何时使用

研究报告引言、较长方案的问题陈述和需要建立论证基础的文章可以参考。决策备忘、例行周报和 README 通常更适合先写结论。

## 自检

1. 读者能否说出缺口是什么？
2. 本文的位置能否用一句话复述？
3. 缩短背景后，问题和主张是否更清楚？
