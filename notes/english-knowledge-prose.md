# 英文知识工作散文：几条可迁移纪律

本仓标准中英通用；仓库正文以中文为主。英文稿评审时，优先用下列纪律（启发式），再回八维。

## 优先检查

1. **Characters as subjects, actions as verbs**（Williams）— 见 `traditions/williams-style.md`  
2. **Omit needless words**（Strunk）— 见 `traditions/strunk-white-elements.md`  
3. **No dying metaphors / verbal false limbs**（Orwell）— 见 `traditions/orwell-politics-and-english.md`  
4. **Nominalization 降级**（Lanham 思路）— 见 `traditions/lanham-revising-prose.md`：把 *the implementation of optimization* 改回 *we optimized X*  
5. **Old → new** 信息序 — 句首接上文，句末放新信息

## AI 英文初稿高频病征

- delve / leverage / landscape / robust / "In today's fast-paced…"  
- "It is important to note that…" 零增量前缀  
- "It's not just X, it's Y" 伪对照  
- 全篇匀速长句，无短句落锤  
- 过强模态：*clearly / obviously / proves* 配弱证据

## 与中文得体

英文写成英文，不从中文排比镜像；中文稿勿硬塞英文套话。见 `principles/decorum.md`。
