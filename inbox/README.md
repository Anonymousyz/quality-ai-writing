# inbox — 本地草稿收件箱

本目录只放**本地改前/改后草稿**，供入库前整理使用。

## Git 规则

整目录被 `.gitignore` 忽略（本 README 除外）。草稿**永不进入公开仓库**。

## 入库流程

1. 将改前、改后文本放入本目录
2. 使用 `skills/case-intake` 技能整理成案例草稿
3. 完成**虚构化/脱敏**后，移入 `cases/`

## 入库决策规则

删掉专名与内部数字后，仍像「只有作者能写出的取舍」→ 可改写成公开判例。

删完只剩空壳，或仍能被认出真实来源 → **禁止入库**。

## 脱敏红线

- 不含真实客户、雇主、项目名或内部数据
- 案例必须虚构化后方可公开
