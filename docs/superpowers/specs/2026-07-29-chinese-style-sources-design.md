# 中文文风来源与规则融合设计

## 目标

把 Notion 写作体系中新增的中文文风材料，转化为 `quality-ai-writing` 可长期维护的公开内容。仓库不再把“去 AI 味”理解为词表替换，而把它放回判断、证据、结构、自然中文和任务可用性的完整审稿过程。

## 公开边界

- 受版权保护的文章不全文转载。
- 每篇材料保留作者、题名、发表信息、原始链接、简短摘要和必要短摘录；摘录、转述、仓库规则严格分开。
- 规则只在写明适用场景、例外和来源映射后进入默认标准；未经过真实文本检验的内容仅作为启发式参考。

## 信息架构

1. 新增 `traditions/chinese-style-sources.md`：建立“内容与文风、自然中文、界面任务文案”三条来源线索，并列出材料索引、原始链接和仓库映射。
2. 新增三篇传统/参考短注：叶圣陶的公共写作与修改、现代文风讨论的内容与修改、Ant Design 的任务文案原则。余光中现有短注改为补足出处和“信号不是禁词”的边界。
3. 更新 `STANDARD.md`：在写前三问、辞章与使用方式中补入“先判断问题，再改语言”“表达门不替代事实核验”“任务型文字必须写清状态、动作、后果与下一步”。
4. 更新 `principles/stale-words.md` 与 `principles/decorum.md`：补充自然中文诊断、范围强度、主体与动作、术语一致等可复查问题。
5. 更新 `skills/pre-sign-review/SKILL.md`：把“表达”检查明确为与事实/来源独立的质量门，并加入中文任务文案分流；不改变其不打分、不自动批准的边界。
6. 更新 `README.md`、`traditions/README.md`、`CHANGELOG.md`：说明新增来源、目录和版本变化。

## 验收

- 每一项新增材料都有可访问的原始出处；不把二手总结写成作者原话。
- 每条新增默认规则都有适用条件和例外，能对应现有八维中的至少一个维度。
- 所有 Markdown 内链、版本号、数量和目录说明一致。
- 运行仓库既有单元测试和内容校验；逐项审阅新增中文，避免空泛、翻译腔和伪精密表达。

## 非目标

- 不公开 Notion 私人笔记、原始草稿或真实项目材料。
- 不把来源作者的观点包装成普遍有效的硬规则。
- 不以“AI 味评分”或词频命中替代内容与事实审查。
